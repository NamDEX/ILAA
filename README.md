# Deep Research Agent 1

## One-line pip install
```bash
pip install -r requirements.txt
```

## How to run
1. Set your OpenAI API key:
   ```bash
   # Linux/Mac
   export OPENAI_API_KEY="sk-..."
   # Windows
   set OPENAI_API_KEY="sk-..."
   ```
2. Run the agent:
   ```bash
   python agent1.py
   ```
3. To run self-test:
   ```bash
   python agent1.py --self-test
   ```
